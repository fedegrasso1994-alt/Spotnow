# SOMA Legal Control Register — DSA and copy criteria supplement

## DSA
| ID | Canonical requirement | Priority |
|---|---|---:|
| DSA-01 | SOMA hosting-service classification is documented. | P0 |
| DSA-02 | SOMA online-platform classification for the Spotted layer is documented. | P0 |
| DSA-03 | Micro/small-enterprise status is formally evidenced using the relevant operator, staffing and financial criteria. | P0 |
| DSA-04 | The resulting DSA Section 3 applicability/exemption analysis is documented. | P0 |
| DSA-05 | Public Terms and moderation disclosures match the moderation model actually used. | P0 |

## Copy consistency
| ID | Canonical requirement | Priority |
|---|---|---:|
| COPY-01 | User-facing product/legal copy does not use legacy Tribe terminology. | P0 |

| COPY-03 | User-facing and canonical documentation does not state the superseded Spotted romantic-request daily limit. | P0 |

| COPY-05 | User-facing copy does not present the Privacy Policy as a consent that must be accepted. | P0 |
