# SOMA — DSA Classification Assessment v1.0

Date: 2 November 2026

SOMA performs hosting-service functions.

For the Spotted layer, SOMA should be treated as an online platform because user content is stored and made available to a context audience without the author individually selecting every recipient.

Private Match/Chat is not itself the basis for public-dissemination classification.

Current status:
- DSA-01 Hosting classification: PASS
- DSA-02 Online-platform classification: PASS
- DSA-03 Micro/small-enterprise status: OPEN FORMAL EVIDENCE
- DSA-04 Section 3 applicability: OPEN pending DSA-03
- DSA-05 Terms/moderation disclosure: legal design PASS / runtime verification required

Likely microenterprise status still requires formal documentation of operator/entity, headcount, turnover/balance-sheet information and linked/partner-enterprise assessment.

No basis exists for VLOP treatment in the pilot.

Operational requirements are defined by DSA-* in the Legal Control Register.
